# SpotiFree V2 🎵

העתק מלא ועצמאי לחלוטין של Spotify הפועל ברקע גם כשהמסך כבוי, על המחשב ובטלפון הנייד (כולל גלישה סלולרית 4G/5G), ללא שום תלות במחשב דולק או בשרתי צד-שלישי שקורסים.

---

## 🚀 יתרונות SpotiFree V2 על פני הגרסה הקודמת
1. **0% תלות במחשב / שרת ביתי:** הנגן שולף ישירות קובצי שמע Progressive MP3 משרתי ה-CDN הגלובליים במהירות מיידית (< שניה אחת).
2. **נגינה רציפה ברקע במסך נעול/כבוי:**
   - **באפליקציית אנדרואיד (APK):** מופעל `Foreground Service` מובנה עם סוג `mediaPlayback` ו-`WAKE_LOCK`, כך שמערכת ההפעלה לא עוצרת את המוזיקה לעולם.
   - **בדפדפן / PWA:** אינטגרציה מלאה עם `MediaSession API` לשליטה מאוזניות, שעונים חכמים ומסך הנעילה.
3. **הורדות להאזנה אופליין:** שמירת שירים ישירות ל-IndexedDB בזיכרון המכשיר להאזנה במצב טיסה או ללא אינטרנט.
4. **מילים מסונכרנות (Karaoke):** סנכרון חי לפי מילי-שניות עם הדגשת מילים וקפיצה בלחיצה (Click-to-Seek).
5. **ייבוא פלייליסטים:** ייבוא מלא של פלייליסטים מספוטיפיי ויוטיוב ישירות בדפדפן.
6. **אנליטיקות אישיות:** מעקב זמן האזנה, אמנים מובילים ושירים אהובים.
